pfSense Firewall Lab (GNS3 + Docker)

A segmented network lab (WAN / DMZ / Admin / Internal) built in GNS3 with pfSense and Docker service nodes.
Source repo: thebeaarr/gns3-pfsense-firewall-lab
What this is
A practice environment for segmentation, service exposure, and later: NAT + firewall policy testing.
Status
Topology + initial deployment documented.
(Rules/NAT are planned; not the focus of this write-up yet.)

Network plan

  • WAN (untrusted): 172.17.0.0/24 — pfSense em0 = 172.17.0.1
  • DMZ (services): 192.168.0.0/24 — pfSense em1 = 192.168.0.1
  • Administration (management): 192.168.1.0/24 — pfSense em2 = 192.168.1.1
  • Internal (trusted): 192.168.2.0/24 — pfSense em3 = 192.168.2.1

Nodes / services

  • DMZ: DNS, Web, Mail, FTP (Docker)
  • WAN: external client/attacker node for testing
  • Admin: workstation used to access pfSense WebGUI
  • Internal: PC1 / PC2

Topology

pfSense access

WebGUI is accessed from the Administration network at: https://192.168.1.1

How to run (high-level)

  • Open GNS3 and import/open gns3/firewall.gns3
  • Make sure pfSense and Docker integration are configured in GNS3
  • Build the Docker images under containers/ (example: containers/dns)
  • Start the topology
If images don’t show: it usually means the file path/name in the GitHub repo is different. In that case, tell me the exact image filenames inside gns3-pfsense-firewall-lab/docs/ and I’ll adjust the links.
