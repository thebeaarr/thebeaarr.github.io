pfSense Firewall Lab (GNS3 + Docker)

Segmented network: WAN / DMZ / Admin / Internal.
Repo: thebeaarr/gns3-pfsense-firewall-lab

Goal

Build a small environment that is realistic enough to practice: segmentation, NAT, and firewall policy. pfSense is the gateway between all zones, and Docker containers simulate services/hosts.

Network plan

  • WAN (untrusted): 172.17.0.0/24 — pfSense em0 172.17.0.1
  • DMZ (services): 192.168.0.0/24 — pfSense em1 192.168.0.1
  • Admin (management): 192.168.1.0/24 — pfSense em2 192.168.1.1
  • Internal (trusted): 192.168.2.0/24 — pfSense em3 192.168.2.1

Services

  • DMZ: DNS, web, mail, FTP (Docker)
  • Admin: workstation to access pfSense WebGUI
  • WAN: attacker/client node for testing
  • Internal: PC1/PC2
